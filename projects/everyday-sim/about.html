平民版 AnyLogic：everyday-sim

把一句生活或小生意里的问题，变成可以播放、可以调参数的模拟。

你不用会建模。告诉 agent 你的问题，比如「中午要几个店员」「多久能存够首付」「新店靠口碑多久能火」，它会选一种建模方法、问你最多 3 个关键数字，然后生成这样一个页面：

  • 动画：看过程怎么发生，比如队伍什么时候排起来。
  • 结果：关键数字和「多数情况下」的范围，因为现实有运气成分。
  • 假如…：拖滑块马上重算，和原方案对比。
  • 模型结构：模型假设了什么、没考虑什么，方便你判断能不能信。

和 AnyLogic 的对应

AnyLogic这里叫适合的问题示例
离散事件（Process Modeling Library：Source、Queue、Service、Delay、SelectOutput、Sink）流程模型排队、人手够不够、流程卡在哪咖啡店、诊所、办证窗口、仓库出货
系统动力学（Stock、Flow、Dynamic Variable）存量模型总量随时间怎么累积存钱、还贷、库存、体重、习惯
智能体（Agent、Statechart）个体模型人和人互相影响口碑传播、流感、谣言、换工作
Parameter Variation / Optimization 实验假如…滑块改一个条件会怎样多一个店员、多存 2000
Monte Carlo 多次运行「多数情况」范围运气好坏差多少每个随机模型默认跑 20~30 次

刻意不做的

  • 不做拖拽式建模画布：一般人画不对，改成用对话描述，由 agent 写模型文件。
  • 不做 3D 和地图：成本高，对回答问题帮助小。
  • 不追求精确预测：目标是比较方案、看清趋势，所以每个页面都写明假设和边界。

使用与下载

下载 everyday-sim skill（ZIP），解压后交给支持技能的 AI agent 使用。生成页面需要 Python 3.8+ 和 Node 16+，无需安装额外软件包。

这里的数字只是示例假设，并非对真实情况的预测；请在「假如…」中修改参数，并查看模型假设和限制。
