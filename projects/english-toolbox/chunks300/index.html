iPhone / iPad

iOS 不让网页使用下载的高级声音（在 iOS 27 的 Safari 上实测只有基础版）。想听 Ava，可以用系统自带的「朗读屏幕」：

  1. 设置 → 辅助功能 → 朗读内容：打开「朗读屏幕」，声音选 英语（美国）→ Ava（高级）
  2. 打开本页「语块库」，滚到要开始的场景
  3. 两指从屏幕顶部向下滑，系统会用 Ava 连续朗读并自动翻页

这种方式不会记录播放位置，也不能调重复次数，适合纯泡耳朵。

Mac
  1. 系统设置 → 辅助功能 → 朗读内容
  2. 系统声音 → 管理声音
  3. 英语（美国）里勾选 Ava（高级）或 Zoe（高级）
  4. 刷新本页，选带 ★★★ 的声音
Windows 电脑
  1. 用 Edge 浏览器打开本页
  2. 声音列表里会出现 “Microsoft Ava / Andrew / Emma … Online (Natural)”
  3. 选带 ★★★ 的 Natural 声音，联网时最自然
Android / Chrome
  1. Chrome 自带 “Google US English”，比系统默认好
  2. Android 可在 设置 → 无障碍 → 文字转语音 里安装 Google 语音引擎的高质量英语声音

星级说明：★★★ 高级 / 自然声音，★★ 较好，★ 普通。列表会把最好的排在最前面，第一次打开会自动选中。

「AI 真人声」是预先生成的录音（Kokoro · af_heart），每个场景第一次播放时加载约 0.7MB。「本机朗读」用手机自带声音，不用加载。中文部分始终用本机朗读。设置、位置、收听次数都会自动保存在这台设备的浏览器里。快捷键：空格 播放/暂停，← → 上一条/下一条。

为什么背语块，而不是单词

母语者说话时，大部分是成块提取的现成组合（figure out、it turns out that、let me get back to you），不是一个词一个词拼出来的。语块存进脑子以后，开口就不用先想中文再翻译。

一轮循环

  1. 泡耳朵：范围选“全部”，模式“语块 → 例句”，通勤或做家务时连续听。
  2. 跟读：重复设 2 遍，第二遍跟着念，模仿重音和连读。
  3. 自测：模式换成“中文 → 停顿 → 英文”，停顿时自己先说，再听答案。
  4. 标记：能脱口而出的标“已掌握”，之后范围切到“只播未掌握”。
  5. 造句：每天挑 3 个，换成自己工作里的事说一遍。
